# [강재성] sprint7

Vite 기반 프론트엔드를 Next.js App Router로 전환하고, 이전 미션의 Express API에 연결한 자유게시판을 구현했습니다. 게시글·댓글 CRUD와 제목 검색을 지원하며, 입력 검증·저장 중 중복 요청 방지·실패 시 입력값 유지 처리를 적용했습니다.

## 구현 사항

- [x] Next.js 전환 및 기존 홈·상품 목록·등록·상세 화면 연결
- [x] 게시글 목록 GET, 최신순 드롭다운, 제목 일부 검색
- [x] 최신 게시글 3개를 별도로 요청하는 베스트 영역
- [x] 프론트 기본 이미지·임의 닉네임·좋아요 수 표시
- [x] 게시글 등록·수정 공통 폼과 정확한 placeholder
- [x] 제목·내용 입력 시 저장 버튼 활성화 및 POST·PATCH 연결
- [x] 저장 성공 시 반환된 ID의 상세 페이지로 이동
- [x] 게시글 상세 GET·DELETE와 삭제 확인
- [x] 댓글 GET·POST·PATCH·DELETE 및 커서 기반 더 보기
- [x] 댓글 수정 취소·삭제 확인, 공백 입력 차단 및 오류 표시
- [x] 모바일·태블릿·데스크톱 대응 스타일과 정렬 메뉴 키보드 조작

## 주요 변경

- `app/(main)/layout.jsx`에 공통 헤더·푸터를 배치하고 API는 `app/_api/`, 공통 UI는 `components/`, 정적 이미지는 `public/asset/`에 정리했습니다.
- 프론트의 `/api` 요청을 `API_BASE_URL`의 백엔드로 전달합니다. 로컬 프론트는 3001번, 백엔드는 3000번 포트를 사용합니다.
- 게시글 API에 `searchBy=title`을 추가했습니다. 생략 시 기존 제목·내용 검색은 유지됩니다.
- 상태 변경은 서버 성공 응답을 받은 뒤 반영하고, 조회 중 화면을 떠나면 해당 요청을 취소합니다.
